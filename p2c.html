## Audio-cmn 音節錄音

`public/audio/*.mp3` 與建置後的 `dist/audio/*.mp3` 取自 https://github.com/hugolpz/audio-cmn 的 `64k/syllabs/`。

上游版本：`ff9ed3d0c631195bd2c06f39450f3264c7124040`。

朗讀者：**Chen Wang**。音源專案管理、壓縮與檔名整理：**Hugo Lopez**（PLIDAM / INALCO）。錄音軟體與技術支援：**Nicolas Vion**。

上游 README 標示音節錄音授權為 **CC BY-SA**，未在該表指定版本。本專案保留此聲明，不把錄音當作自有作品，也不改為封閉授權。再散布時請保留朗讀者、来源及 CC BY-SA 聲明；改作須遵循上游的相同方式分享要求。上游完整聲明見 `licenses/audio-cmn-README.md`。

音源位元組未更改；僅去除檔名前綴 `cmn-`。上游 `cmn-jv4.mp3` 依漢語拼音拼寫改名為 `ju4.mp3`，以與第一至第三聲的 `ju` 檔名一致。沒有把第一聲檔案複製成輕聲；輕聲採詞語語境示範。

上游包括部分音節的四聲語音練習錄音；錄音存在不代表每個聲調都有常用漢字。

## Audio-cmn 完整詞語錄音

`public/word-audio/*.mp3` 取自相同上游版本的 `96k/hsk/`，朗讀者 **Yue Tan**，授權按上游 README 為 **CC BY-SA**（表內未指定版本）。159 段原始錄音位元組不變，檔名改為詞語的 SHA-256 前 16 字以便在本機網頁使用。繁體顯示文字以 OpenCC 對應上游簡體檔名；來源檔名及 SHA-256 詳見 `WORD_AUDIO_PROVENANCE.json`。音源管理及技術人員同上，保留上游署名及相同方式分享要求。

## 示範音播放保護版本

`public/audio-protected/*.wav` 包括 49 段仍採用 Chen Wang 原音的播放保護版本。保留原始錄音解碼所得的全部 16 位元 PCM 取樣與原採樣率，只在首尾加入 250／350 毫秒靜音；沒有製造音高、拉伸聲調或拼接詞語。原始 MP3 仍保留於 `public/audio/`。改作沿用上游 CC BY-SA 聲明，詳見 `AUDIO_PLAYBACK_PROTECTION.json`。

## 指定音節修復錄音

29 段替換或新增的音節錄音取自 https://github.com/davinfifield/mp3-chinese-pinyin-sound ，上游提交 `aa25ecce7b7fb02757b2c2b8e3c01aa975812edc`，授權 **Unlicense**。上游未提供朗讀者姓名。完整授權與 README 保留於 `licenses/mp3-chinese-pinyin-sound-LICENSE.txt` 及同目錄 README。原始 MP3 位元組保留於 `public/audio-repairs/`。

修復版本保留全部解碼取樣、原採樣率、音高及速度，對指定較小聲的音節施加靜態增益（峰值上限 0.90），在音檔首尾 10 毫秒淡入／淡出，再加 250／350 毫秒靜音，避免播放邊緣跳變。WAV 使用內容雜湊檔名，以避開舊快取。檔案、來源、處理及雜湊見 `AUDIO_REPAIR_PROVENANCE.json`；不表示已完成真人逐段聆聽。

## 第四輪內容修訂新增錄音（2026-10）

聲母 t、n、l 的呼讀音 tē、nē、lē 取自 https://github.com/hugolpz/audio-cmn 的 `64k/syllabs/`（朗讀者 **Chen Wang**，CC BY-SA，上游版本 `ff9ed3d0c631195bd2c06f39450f3264c7124040`）；dē 沿用本版已有的同一來源錄音。這四段示範音按上述「播放保護」方法，只在首尾加入 250／350 毫秒靜音，音源取樣未改動。

另加入一批詞語錄音，取自同一上游的 `64k/hsk/`（朗讀者 **Yue Tan**，CC BY-SA），音源位元組未更改，只按繁體詞語建立索引。這些錄音沒有人親耳逐一聆聽，只以檔名對應詞語。

## 網上版（2026-10）

網上版把錄音分成多個錄音包，放在網站的 `audio/` 資料夾，用到時才自動載入：每段錄音只下載自己那一小段（HTTP Range）；網站或網絡不支援時，改為下載整個錄音包。單字音節錄音（Chen Wang）和詞語錄音（Yue Tan）取自 audio-cmn（CC BY-SA），音源位元組未更改；播放保護版本的示範音（原為 WAV）在網上版轉成 64 kbps 單聲道 MP3，首尾靜音保留。沒有內附錄音的詞語、成語和句子，使用裝置內建的普通話語音朗讀。

全班排行榜由老師自己的 Google 試算表（Apps Script）記錄，只保存學生輸入的名字或匿名稱號、分數和題目設定。

## 指定詞例合成語音

`public/example-audio/` 包含 17 段完整詞例，使用 Microsoft Edge 線上朗讀的 **zh-CN-XiaoxiaoNeural** 普通話語音，以 `edge-tts` 產生，語速 -12%，音高不作調整。此部分為合成語音，並非真人或 Audio-cmn 錄音；不套用前述錄音的 CC BY-SA／Unlicense 聲明。edge-tts：https://github.com/rany2/edge-tts 。

保留生成的 MP3 原始位元組與全部解碼取樣，僅加入首尾 250／350 毫秒靜音。來源、文字、教學目標拼音、輕聲位置、服務回傳的完整詞語邊界及雜湊見 `EXAMPLE_AUDIO_PROVENANCE.json`。目標拼音與檔案解碼檢查不等同聲學人工驗收。


**Audio-cmn** aims to provide hight quality & easy to use Chinese words audio recordings for modern web & mobile application. Audio-cmn is all
* an original work by the recording of chinese syllabs
* a curation work reusing pre-existing audios from SWAC Recorder
* a post-processing work by providing light & optimised `.mp3` files rather than the huge original `.flac` files.
These audios are thus suitable for mobile application developments.

### Voices
| # of items | Naming          | Set's specifics | Authorship |
| :--------- |:---------------:|:----------------|:-----------|
| 1707       | `cmn-zi4.mp3`   | syllabs v.2    | Chen Wang, CC-by-sa |
| +8000      | `cmn-名字.mp3`   | HSK_2000 list (words,zi)  | Yue Tan, [CC-by-sa](http://packs.shtooka.net/cmn-caen-tan/readme.txt) |

### Structure
Type of data :
* **.../syllabs/cmn-{tonedPinyin}.mp3** : 1707 chinese syllabs (all)
* **.../hsk/cmn-{hanzi}.mp3** : 5,596 HSK_2000 words and characters

### Qualities
* **/96k/** - best audio quality, improvement from 64k is not perceptible.
  *  no syllabs folder
  * /96k/hsk/
* **/64k/** - optimal audio quality for voice recording.
  * /64k/syllabs/
  * /64k/hsk/
* **24k-abr** - brutally optimized : ~2 times lighter, for 80% of the audio quality.
  * /24k-abr/syllabs/
  * /24k-abr/hsk/
* **18k-abr** - brutally optimized : ~3 times lighter, for 60% of the audio quality.
  * /18k-abr/syllabs/
  * /18k-abr/hsk/


### Missing audios ?
The current HSK audio database was build upon the official `HSK 2000`, published in 2000. The HSK 2000 is thus near fully covered (at least 8596 out of ~8800). List comparison with the last `HSK 2012` words list is available and done via :

```bash
bash ./hsk-missing-audios.bash  HSK2012_all.txt    # List missing audios, compared to input list of words
bash ./missing-audios.bash --help              # Tiny manual
```

Current difference: [582 HSK2012 words which are missing human audios](http://jsfiddle.net/fduyws3x/2/). See files in `./lists/` .
