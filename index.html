📚 學習先學：聽清楚、看清楚、讀出來。

🔊 學習一點讀與四聲點聲母、韻母聽呼讀音，看口形；每個音都有四聲和例字，用四聲過山車認識四聲、輕聲與變調。開始學習 → 🧩 學習二拼合與收藏選聲母、韻母和聲調，聽三步拼讀，把學會的音節收進收藏冊。開始學習 → 🎢 學習三語流音變「一」「不」變調、三聲連讀、輕聲和兒化：每個例子都可以聽，學完到練習九至十一練習。開始學習 →

👂 聽音辨音聽讀音，分辨聲母、韻母和聲調。

📢 練習一聲韻尋寶聽讀音，找出字的聲母或韻母；可按單韻母、複韻母、鼻韻母、介音韻母分類練習，也可只聽呼讀音。開始練習 → 🎵 練習二聲調小偵探聽讀音分辨四聲和輕聲；可專練第二聲與第三聲、第一聲與第四聲。開始練習 → 👂 練習三順風耳對決聽讀音，從相近的拼音中選出正確的一個：平翹舌、n 與 l、前後鼻音等。開始練習 →

✏️ 拼寫拼音掌握拼寫規則，自己組裝拼音。

🪄 練習四拼寫魔法屋選出寫法正確的拼音：ü 的兩點、標調位置、iu ui un 省寫、y 和 w。開始練習 → 🧱 練習五聲韻組裝王聽讀音、看漢字，選聲母、韻母和聲調組裝拼音；每題附拼寫步驟解說。開始練習 →

🀄 漢字與拼音漢字和拼音互相配對。

🔤 練習六漢字找拼音看漢字，選出正確的拼音；可專練平翹舌、前後鼻音、聲調、輕聲等。開始練習 → 🀄 練習七拼音找漢字看拼音，選出正確的字、詞或成語；每題附答案解說。開始練習 →

🗣️ 粵普對譯把粵語說法換成普通話說法。

🗣️ 練習八粵普對譯粵語說法和普通話說法互譯：雪櫃→冰箱、放飛機→放鴿子、一架車→一輛汽車、佢喺邊度？→他在哪裏？答完讀出普通話並附拼音。開始練習 →

🎢 語流音變說話時讀音的變化：變調、輕聲、兒化。

🎢 練習九變調小達人「一個」讀 yí gè、「不是」讀 bú shì、「你好」讀 ní hǎo：聽讀音，判斷說話時讀第幾聲。開始練習 → 🤫 練習十輕聲悄悄話找出讀輕聲的字（桌子、爸爸），選出輕聲的拼音，分辨「東西」dōng xi 和 dōng xī。開始練習 → 🌀 練習十一兒化捲舌王花兒 huār、一會兒 yī huìr：兒化的拼寫，分辨要不要兒化（花兒／女兒），認識兒化詞語的意思。開始練習 →

用 iPad 時：讀音在用到時才下載，第一次播放通常不到一秒；沒有聲音時，請再按一次播放，並檢查音量和靜音設定。
連線對戰：練習頁的「雙人對戰」和「小組對戰」可選「連線」，多部 iPad 同時作答同一組題目（小組最多 40 組），可設比賽限時，一起倒數開始，完結時頒獎給首三名。
